# 🛍️ Catálogo de Produtos

Projeto desenvolvido em **React** utilizando **Vite**, com o objetivo de praticar a criação de componentes reutilizáveis, gerenciamento de estado e formulários.

## 📋 Sobre o projeto

A aplicação permite visualizar uma lista de produtos e adicionar novos produtos por meio de um formulário.

O projeto foi desenvolvido como atividade prática para estudar os principais conceitos do React.

## 🚀 Tecnologias utilizadas

* React
* Vite
* JavaScript
* HTML
* CSS

## 📚 Conceitos praticados

* Componentes React
* Props
* `useState`
* Renderização de listas
* Formulários
* Eventos
* Componentização
* Gerenciamento de estado

## ▶️ Como executar o projeto

### 1. Instale as dependências

```bash
npm install
```

### 2. Inicie o servidor de desenvolvimento

```bash
npm run dev
```

### 3. Acesse no navegador

O Vite irá mostrar o endereço local, normalmente:

```text
http://localhost:5173
```

## 🎯 Objetivo

Praticar o desenvolvimento de uma aplicação React utilizando componentes, propriedades, estados e formulários, criando uma interface simples de catálogo de produtos.
